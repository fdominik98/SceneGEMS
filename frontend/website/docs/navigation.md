# Left navigation menu

Expand the menu with the hamburger (☰) button when the left pane is collapsed. Menu items appear in this order:

1. **Domain Configuration**: Edit YAML domain presets (COLREGS, vessel types, obstacles).
2. **Scene Generation**: Author functional specs and generate scenes.
3. **Simulation**: Run playback and live simulation with monitoring.
4. **Connect to WARA-PS**: Configure MQTT connection and geofence.
5. **Documentation**: This reference (served at `/docs/`).

The active view is remembered across browser sessions. When simulation initializes successfully, the app automatically switches to the Simulation view.
